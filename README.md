# VOC 월간 보고서 생성기

친구의 월간 상담 보고서 수작업을 줄이기 위한 브라우저 기반 프로토타입입니다.
2026-09-17 기준 ChatGPT Sites에 배포된 소스의 개인 GitHub 백업입니다.

## 실행

Node.js와 package.json에 지정된 pnpm 버전이 필요합니다.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

프로젝트의 실행 스크립트와 구성은 Sites의 Vinext starter 기반입니다.
일반 Next.js 프로젝트나 Cloudflare Pages용으로 전환한 상태는 아닙니다.
독립 호스팅 이전 시 빌드 및 실행 스크립트를 별도로 검증해야 합니다.

## 입력 파일

1. 월간 상담내역 XLSX: 고객사명, 협력사명, 상담명, 상담자명, 상담일자, 상담구분, 우선순위, 상담내용.
2. 기준표 XLSX:
   - 첫 번째 시트: 상담사(담당자), 고객사.
   - 대기업협력사 시트 또는 두 번째 시트: 협력사명.
   - 대기업 목록에 없는 협력사는 시장으로 분류합니다.

## 출력

전체, 협력사, 일반상담, 클레임상담, 협력사 요약, 메인요약의 6개 시트를 생성합니다.
협력사 요약은 사람이 웹 화면에서 작성합니다.
상담내용의 -> 및 → 구분자는 줄바꿈과 → 표기로 변환합니다.
메인요약은 담당자별 전체 상담과 고객사별 클레임을 별도 표로 표시합니다.
파일 처리는 브라우저에서 수행하며 상담 파일을 서버로 업로드하지 않습니다.

## 현재 구현과 제한

- 분류는 아직 구현되지 않아 출력 칸이 비어 있습니다. 사용자에게 항목과 규칙을 확인받은 뒤 구현합니다.
- 상담구분의 공백 및 알려진 표현은 정규화하지만 오타 자동 판정이나 사용자 매핑 화면은 없습니다.
- 고객사 이름이 기준표와 일치해야 담당자별 집계에 포함됩니다. 미등록 고객사 경고는 아직 구현하지 않았습니다.
- 협력사 이름 매칭은 공백 제거 기준입니다. 접두어 및 오타는 자동 병합하지 않습니다.
- 날짜 및 건수 일부는 문자열로 출력됩니다. Excel의 날짜 정렬과 숫자 정렬은 후속 검증이 필요합니다.
- 기존 원본 상담내용의 줄바꿈은 공백 정규화 과정에서 사라집니다. 화살표 줄바꿈만 복원됩니다.
- 상세 행 높이는 추정값이며 최대 180pt입니다. 매우 긴 내용은 잘릴 수 있습니다.
- 빈 대기업 목록 시트에 헤더가 없으면 오류가 납니다. 시트가 없는 경우에는 모두 시장입니다.
- Windows Excel에서 최종 레이아웃 및 집계 검수는 아직 완료하지 않았습니다.

주말에 분류 항목을 확인한 뒤 위 제한을 순차적으로 보완할 예정입니다.
구현 코드의 중심은 app/page.tsx입니다.

## 보안 및 백업

상담 샘플, 생성된 보고서, 환경 변수 및 인증 토큰은 이 백업에 포함하지 않았습니다.
.openai/hosting.json의 project_id는 기존 Sites 식별자이며 비밀키가 아닙니다.
현재 Sites 배포를 재현하기 위해 관련 구성은 유지했습니다.
이 백업 작업은 기존 Sites 사이트의 배포나 접근 범위를 변경하지 않습니다.
